# Job Prep AI 🤖

An AI-powered interview preparation platform that helps users analyze their resumes, identify skill gaps, and prepare for technical interviews.

## 🚀 Features

- 🔐 User authentication with JWT
- 📄 Resume upload and PDF parsing
- 🤖 AI-powered resume analysis using Google Gemini
- 📊 Skill gap analysis
- 💬 AI-generated interview questions
- 🎯 Personalized interview preparation
- ⚛️ React-based frontend
- 🛠️ Node.js and Express.js backend
- 🗄️ MongoDB database
- ✅ Input validation using Zod
- 📦 Structured AI responses using JSON Schema
